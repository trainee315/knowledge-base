发布日期：2026-11-11。按用户2026-11-11“完成0.0.1版本并推送”指令归档发布，自动验证和独立复核已通过；版本号0.0.1，Git标签 `v0.0.1`。本目录归档已落地行为，后续需求使用新的目标版本目录。本版本实现提交与发布标签对应关系见 [版本历史](../version-history.md)。

本项目是工作Agent通过CLI维护的单人单机知识库。Node.js24+、TypeScript、Vue3和Vite；所有正式状态保存在本地文件，不依赖数据库或常驻业务服务器。PPC可转发本项目CLI，业务及数据仍由本项目管理。

## 已交付能力

- 任意文件入库，按扩展名分类，UUID稳定身份；SHA256默认去重、显式副本、内容版本与历史原件、软删除恢复、引用保护的永久清理。Markdown/TXT/JSON解析；其它格式保留原件、文件名关键词及未支持标记。
- schemaVersion=1的JSON meta与插件分区；通用组织实例和独立组织方式定义均可CRUD，支持配置、启停及使用中删除保护。默认标签/关键词/体系方式首次可写初始化登记一次，显式删除不被下一次load重建。
- 静态插件显式单向依赖；载入前检查完整DAG、版本和循环，依赖优先加载/迁移/刷新，失败阻断依赖方并持久保留状态，逆序停用且保留数据。
- 内容、关键词、标签、评分、任务、整理、体系与夜间策略八插件。组合查询遵守条件间AND、同类多个值OR，返回原因与解析状态；评分仅召回候选，工作Codex或人工提交最终判断，人工接受/拒绝优先保护，过期输入拒绝写回。
- 持久队列去重、断点、重试、超时隔离与预算；显式schedule tick/run推进夜间策略，不注册系统任务、不付费调用。默认离线词汇评分，可通过代码接口替换provider。
- 统一CLI，UTF8 JSON文件/stdin输入、单JSON对象stdout与退出码；资源/meta/组织/方式/插件管理、备份恢复、检查及索引重建。普通命令处理后退出。
- Vue只读临时预览，Markdown、UUID图片/资源链接、原件下载、组织/方式/体系及插件状态。loopback同源服务显式start/status/stop，使用canonical目录与OS IPC避免别名重复实例。
- 单写者OS IPC互斥、跨文件journal redo、原子替换和并行一致读取；规范路径/schema/hash/引用全量恢复预检、内部symlink/junction拒绝，索引及缓存可重建。
