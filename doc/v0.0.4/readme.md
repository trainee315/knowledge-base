# v0.0.4 组织文档浏览

2026-11-11用户验收通过，包括文章概览选中高亮。正式包与CLI版本为0.0.4，Git发布标识为v0.0.4；继承已发布v0.0.3。

## 交付行为

组织方式→具体条目→关联文档→正文。标签支持任意/全部匹配，关键词按完整归一化词组选取，体系按目录递归汇总并去重，项目跟踪按固定版本读取历史正文。通用组织按显式资源引用预览。桌面三区、窄屏逐级阅读；URL恢复筛选、分页与阅读位置；当前文章概览有唯一选中样式，历史条目按entry ID区分。

所有浏览为只读，数据结构无迁移，未增加真实模型调用。已知边界：不提供组织编辑、拖拽目录或自动合并项目事实；项目全文读取失败不回退当前资源。
