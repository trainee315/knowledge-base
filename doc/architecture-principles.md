# 项目架构原则

自 v0.0.6 起适用。知识库面向单人单机使用。应用基础层提供按数据目录显式启停的本地常驻服务、SQLite 接入、命令执行与网页 API。CLI 负责解析本地输入并连接服务，构建网页由服务承载，Vite 开发页面代理同一服务。

cron 是可启停的业务插件。启用时，它根据持久化计划调用已注册的业务任务。停用后，服务、CLI、网页和其他可用插件照常工作，已有计划和历史仍保留。具体任务继续遵守所属插件的预算、并发和幂等规则。

资源内容、元数据、组织及现有插件业务数据保留文件存储。服务配置、计划及运行记录存入 SQLite。服务按操作打开和关闭业务会话，模型调用期间释放文件库写锁。恢复文件事务和处理待同步的周期变更后，才开始调度。

浏览接口只公开所需数据。业务接口和生命周期控制在回环地址上运行，校验请求来源。备份包含文件库和持久数据库，运行目录中的 PID、控制令牌等进程状态随服务启动重新生成。
