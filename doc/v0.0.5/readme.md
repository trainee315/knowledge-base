# v0.0.5 记录侧

2026-11-12用户验收通过，包括自由记录、session转录和组织实例可视化配置。正式包与CLI版本0.0.5，Git标识v0.0.5，继承已发布v0.0.4。

自由记录接收文本、Markdown文件和stdin，保存原始正文，以requestId保障重试幂等。Session转录按项目和条件筛选本机Codex主会话，独立生成新增内容的压缩记录，保留来源消息范围与处理身份。CLI提供只读预览、主动执行、到期检查、重试和历史补录，记录、组织引用和进度采用原子提交与可恢复任务。

组织实例详情提供概览、关联记录和配置编辑。开发与构建预览共用本地接口，支持修订冲突、草稿预览、边界保护和窄屏操作。配置、读取及预览保持零模型调用，执行时使用显式预算。

已知边界包括来源私有格式变化、超大完整轮次、有限上下文、历史状态消解和语义准确度。凭证模式过滤已覆盖发送及落库边界，历史原件和旧版本仍由本地库保留。运行和验证证据在下列文档记录。
