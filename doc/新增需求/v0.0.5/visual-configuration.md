# 组织实例可视化配置补充需求

本项纳入 v0.0.5 用户验收。入口为组织方式、实例、实例详情，支持 Session 转录实例新建，以及概览、关联记录、实例配置三个页签。

配置表单覆盖基础属性、目录与包含/排除筛选、关注点与 profile、周期和预算。创建与编辑共用表单，支持保存、取消、修订冲突、执行忙碌提示和草稿保留。URL 使用组织 UUID，刷新和前进返回恢复详情页签及阅读目标，窄屏逐级操作。

开发服务器与构建预览使用同一本地配置接口，共用 CLI 校验与事务。写入仅在提交期间持锁。详情提供必要摘要，profile 只显示模型与凭证可用性。

草稿可在保存前预览增量或显式历史范围，返回候选范围、规模及跳过原因。预览和配置管理零模型调用，预览零业务写入。修改表单后旧预览标记过期。

普通属性、关注点、profile、预算和周期修改保留发现边界。来源、目录、日期、时区及包含/排除条件修改自保存时生效，历史使用显式补录。冻结任务和成功覆盖保留。已有实例沿用已存边界。

验收覆盖网页/CLI互通、校验、冲突、忙碌/锁占用、取消/草稿恢复、边界修正、只读预览、同源/请求体校验、桌面/窄屏与旧浏览回归。正式版本沿用用户验收后发布流程。
