## 公共契约与验收条件

- note add/list/get：text/file/stdin 三选一，严格 UTF-8 字节保真。标题取指定值/首 Markdown 标题/首非空行。每次独立提交新资源，相同 requestId 同参数重放、异参冲突。固定版本读取，无 note update；底层版本及显式删除保留。
- transcript create/list/get/configure/preview/run/tick/records/retry/backfill。session-transcript 配置与组织一一对应，UUID 稳定，别名归一化唯一。
- 起始日期必填，Asia/Shanghai 默认；项目目录精确匹配，可显式包括子目录及额外目录。周期默认关闭，启用必须指定项目目录。
- 包含/排除 session ID、标题及正文关键词：排除优先，同字段 OR、跨字段 AND。默认主 session，完成轮次才处理；状态未知时静默十分钟。
- 日期发现且扫描旧 session 更新；消息位置与指纹确定增量，同时间戳不漏。固定输入截止点，完整轮次分段，超大轮次明确阻塞。
- 默认预算：10 session、200000 输入字节、40000 单段字节、0 模型调用、120000 毫秒。显式正调用预算才调用模型。
- preview/读取/初始化不调用模型。run 与 tick 同流程，CLI 执行后退出，不安装系统任务。
- 每 session 独立任务与成功消息范围，失败不推进。retry 恢复冻结任务；backfill 显式 from/to 补未成功历史，配置/模型/提示词更改不重录成功历史。
- 模型调用在写者锁外；资源、引用、幂等与进度一次重做日志提交。执行租约和令牌隔离并发，恢复不能重复或孤立资源。
- 独立调用现有 Agent profile，输出区分提出/同意/实施/验证、推测/纠正/未解决。结构和来源引用失败明确报错。续录不覆盖旧正文，上下文不重复计为成果。
- 保存 session、消息范围、源/转录时间、指纹、处理器/提示词/适配器版本、模型身份与前篇关联。
- 输出沿用单 JSON、stderr、退出码0/1/2。真实 session、数据库和密钥不得入 Git。

## 验证与交付

覆盖原文/幂等、筛选边界、旧 session 增量/相同时间戳/活动轮次、分段/续录/补录、失败/崩溃/并发、只读零调用及既有 CLI/标签/关键词/组织/项目回归。运行类型检查、完整测试和构建、浏览器验证。

交付可复制验收命令与合成数据，分开报告自动测试、真实模型质量核对和未验证限制。召回粒度与向量仅为后续议题。
