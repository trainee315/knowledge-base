本次授权覆盖原计划的数据保留条款：丢弃当前全部标签（包括人工标签、别名、旧决定及删除抑制）和关键词整理数据，完整保留文档正文、历史、资源身份及其他业务配置；由新算法重新生成并由实施者反复检查、优化后交用户验证。允许并行实施。

## 需求范围

1. 关键词过滤不完整表达、版本号拼接残句和模板套话，优先保留完整术语、实体、代码标识符及原文显式关键词；保留原文位置与双向索引。
2. 标签结合词面、别名与语义证据匹配；支持“预制体 / Prefab”等中英文名称，并处理“事件”等宽泛概念的上下文边界。
3. 区分文档主题相关和正文片元相关，展示实际命中依据，避免来源追溯等模板段落成为主要证据。
4. 自动标签增加概念质量筛选和模板降权；本次按用户明确授权丢弃全部旧标签及关键词，重新生成。日常操作不静默删除或合并人工定义。
5. 建立真实样本质量回归，实施后通过可恢复流程更新关键词索引与标签匹配结果。
