# v0.0.13 关键词双向索引与按需浏览

状态：实现、测试及当前库重建完成；2026-11-13 用户确认验证完成并要求提交。实现日期：2026-11-12。代码基线：`21d0de1`。未正式发布。

本版承接 v0.0.11 验收中发现的关键词列表空状态及刷新缓慢问题。用户要求关键词列表仅展示关键词，选中后再查询关联文档和片元；同步调整生成逻辑，完成后重新生成当前知识库的关键词。

- 关键词来源统一为片元提取结果，文档聚合去重；文档元数据的前 100 项仅作摘要。
- 复用语义 SQLite 建立持久词表和同一套关系数据上的正向、反向索引。
- 列表只查词表；关联文档及片元按需查询、分页加载。
- 生成、更新、删除和恢复同步维护索引，支持任务恢复及缓存失效。
- 完成实现与隔离验证后，对当前库重新生成关键词和关联索引，保留 Markdown 正文及现有标签定义。
