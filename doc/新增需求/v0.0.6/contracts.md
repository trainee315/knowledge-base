# v0.0.6 公共契约

本文定义候选验收目标，具体可复制命令在验证后补入验收文档。

## 应用基础服务

- `service start/stop/restart/status` 显式控制服务。按数据目录实际路径识别单实例，监听回环地址。停服时业务 CLI 返回错误及启动指引，`help` 和服务管理仍可调用。
- `preview start/stop/status` 兼容原入口。停止预览会停止该数据目录的服务及调度。停止服务时暂停接单和调度，等待在途工作结束。
- CLI 保留单 JSON 输出、stderr 日志和 0/1/2 退出码。文件参数相对调用目录解析，stdin 及导入正文保持原字节。开发时先启动服务，再使用 Vite 代理。
- HTTP 服务、生命周期管理和数据库属于应用基础层。停用 cron 只暂停调度，普通知识库操作和网页继续可用。

## 周期与执行

- cron 计划包含注册任务类型、目标、参数、周期、时区、启用状态和配置版本。首批目标是整理与指定 Session 转录实例。支持五字段 cron 和分钟间隔，默认调度时区为 `Asia/Shanghai`。
- 新计划默认停用。迁移实际持久化的旧整理配置和转录间隔，继承已有到期时间。迁移重复执行不得覆盖用户修改，旧周期入口读取和更新 SQLite 中的权威配置。来源筛选时区与调度时区分别维护。
- 混合更新文件业务配置和 SQLite 周期时，先在文件事务中持久化调度意图，再幂等写入 SQLite。未完成同步的计划暂缓执行，启动时恢复。
- 同一计划时点只记录一次。停机错过多个周期时最多补最近一次。同一数据目录的后台任务串行，同一业务目标的主动与定时执行互斥，继续适用已有任务预算和去重。
- 主动执行、显式重试、运行历史可查询。重启后未确认的运行显示中断或结果待核实，由用户决定是否重试。
- 备份包含数据库和业务文件的一致快照，兼容旧格式恢复。恢复出的计划默认停用。
