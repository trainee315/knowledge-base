# v0.0.8 验收方案

状态：字面基线已执行（验收集12个有答案问题命中6个，无答案误召回0）；数值门槛已在调优前冻结于 thresholds.json，验收不得修改。初始语料为30篇已知归属、1篇未知归属，22查询；它是小规模验证，不代表真实私人知识库。

## 样本

使用合成中文工程资料；至少三个项目（含同名 battle 模块），明确术语、改述、条件/例外、旧计划与验证、无答案、未知归属、删除恢复和历史版本。调优及验收按文档主题分离，避免同义问法泄漏；数据集/语料/配置保存 SHA-256。实际私有 session 和凭证不纳入。

比较 literal（现有 organize query）、BM25、semantic、hybrid、hybrid+rerank、task。相同 snapshot、scope、K 与输出字节预算；基线适配只做必要范围筛选和输出投影，不改变字面匹配为语义查询。

## 指标与硬条件

- 零容忍：跨项目/模块、删除泄漏、错误版本定位、read/list 调模型。
- 分别记录 Recall@K、MRR、nDCG、子问题覆盖、条件完整、引用正确、重复率和无答案误召回。历史记录标识与最终任务误用分开。
- 冷启动包括进程和模型加载；热查询分同进程批次、缓存命中，不将短生命周期进程伪称常驻热服务。
- 工作 Agent 的查询/重复/无谓查询、最终测试与证据使用独立评价；脚本预设查询仅检索评价，不算真实 Agent 任务。
- 用量包含 Agent 输入输出、embedding 编码token/次数、重排对数、额外生成、缓存与费用。无计费依据时标未知，本机无 API 费不等于无成本。
- 构建与核心测试负载采用交错配对运行，覆盖 idle/index/query；保存每次耗时、CPU时间、峰值RSS、I/O及可用GPU统计。至少五对，异常或噪声过大报告不确定，不能只挑最快一次。

## 失败与恢复

模型缺失/超时/崩溃、构建中断、源更新、配置修订、删除、恢复、索引损坏、缓存身份变化、同维度不同模型空间、符号链接路径、跨进程并发、超长代码块、BOM/CRLF/Unicode、恶意FTS表达式和极小输出预算。

测试模拟器只能用于注入错误及结构回归，真实模型质量单独报告。外部模型文件或 Agent 执行环境不可用时保留完整功能路径和可复制命令，并列明未验证项目。
