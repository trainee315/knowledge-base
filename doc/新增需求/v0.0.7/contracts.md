# v0.0.7 公共契约

- 每个内置插件均有详情入口，展示用途、版本、依赖、启用和就绪状态，以及插件负责维护的数据。停用或失败时保留可用摘要，并显示不可执行操作的原因。
- 配置复用各插件的校验与领域操作。无可编辑项的插件有明确提示。转录配置进入已有实例详情，scheduler 的周期配置进入 cron。
- 读取配置返回不透明的 `configVersion`，保存携带 `expectedConfigVersion`。服务在同一写入协调区间校验并保存。冲突返回 HTTP 409，网页保留草稿，提供最新值供用户核对。
- 数据集合通过插件适配器返回只读摘要、分页结果和已有详情链接。配置和数据响应不包含凭证、冻结模型输入或内部租约令牌。
- cron 计划支持新增、修改、启停和删除。删除计划保留历史记录。运行历史只读。
- 页面支持 URL 恢复、刷新及浏览器前进后退、未保存导航保护、窄屏和空状态。读取与配置预览不调用模型。
