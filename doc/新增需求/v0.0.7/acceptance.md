# v0.0.7 验收清单

状态：自动验证已通过，待用户验收。验证使用临时数据目录和合成数据，延续 v0.0.6 服务回归。

## 本地操作

按 [服务启动说明](../v0.0.6/acceptance.md) 构建并启动临时库。打开服务 URL，从左侧「插件状态」进入任一卡片的「查看详情」。

- 在「简介」核对插件用途、状态、依赖和维护的数据，点击依赖打开相应详情。
- 在「配置」修改关系评分配置并保存，通过 `relation get-config` 读取。保存前由 CLI 修改同一插件的配置，验证网页保留草稿，并在查看最新配置后选择继续使用草稿。
- 在定时任务插件的「配置」新建、编辑、启停和删除计划。在「维护中的数据」选择「运行历史」，确认删除计划仍可查看既有运行记录。
- 在内容解析插件的「维护中的数据」浏览资源，使用下一页、刷新、前进与后退验证地址恢复，点击资源名称打开详情。

## 自动回归

```powershell
npm test
node --test web/tests/dev.integration.mjs
node web/tests/plugin-detail.mjs
npm run test:web
node web/tests/transcript-configuration.mjs
```

插件详情脚本默认在系统临时目录保留截图和结果，也可用 `KB_PLUGIN_BROWSER_EVIDENCE` 指定路径。
