## 使用入口

打开 http://127.0.0.1:5183/#browse ，或在仓库根目录运行npm run dev后打开该地址。Vite同端口提供页面与只读API。

1. 标签选择png压缩：4篇，可点开阅读。选择游戏架构：5篇；叠加面向agent游戏架构并选全部标签，仍为5篇。
2. 切换关键词，搜索字段投影并选择词组：1篇。点开后刷新页面，组织、词组、正文恢复；浏览器返回恢复前一阅读位置。
3. 体系根据现有数据展示目录树；选择目录汇总后代文档，资源去重但路径位置保留。真实库尚无体系样本，多层顺序与重复位置已由独立夹具验证。
4. 项目开发状态跟踪选择knowledge-base，可阅读基线和累加记录；历史文档显示原件版本、阶段与替代声明。阶段为计划不表示已完成。003发布记录已追加。
5. 窄屏按组织→文档→正文逐级阅读，返回上一级有效，无水平溢出。
