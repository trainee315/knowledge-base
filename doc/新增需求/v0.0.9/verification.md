## 可复制验收

在已启动的本地服务上，用transcript list查出目标实例ID。对同一已完成范围且无新待处理任务时重跑，应零调用、零新增。

```powershell
.\cli.bat transcript list --json
.\cli.bat transcript preview --id "<实例ID>" --preprocessing conservative --json
.\cli.bat transcript preview --id "<实例ID>" --preprocessing off --json
.\cli.bat transcript run --id "<实例ID>" --to "2026-11-12T15:49:41.455+08:00" --preprocessing conservative --max-calls 1 --json
.\cli.bat transcript records --id "<实例ID>" --json
.\cli.bat check --json
```

核对preview的cleaning与request字段，确认读取/预览零模型调用。页面进入实例关联记录，核对三篇续录与来源。自动回归命令如下。
