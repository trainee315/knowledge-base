# v0.0.9公共契约

- 配置及preview/run/backfill命令支持preprocessing=conservative|off|aggressive，新增任务默认conservative。该配置属于生成策略，修改时保留发现时间边界与既有成功覆盖范围。网页插件→project-tracking→配置提供Session实例选择、压缩模式和简短说明，CLI与页面共用该实例的preprocessing。
- 插件配置GET /api/plugins/project-tracking?configKey=<实例UUID>返回三模式及说明，PATCH /api/plugins/project-tracking/config携带configKey、expectedConfigVersion和values.preprocessing。配置版本绑定实例UUID和revision，冲突返回409，页面保留草稿。读取和保存模型调用为零。
- preview/run支持带时区ISO的to截止参数，分批使用同一截止点。已有任务的冻结截止点晚于to时，run保留该任务并返回deferred计数与剩余状态。retry显式沿用各任务冻结范围恢复。每轮处理完整轮次，消息筛选使用原文。
- preview返回每段的原文/清理后正文字符数、字节数、角色和规则统计、原消息位置及处理原因，保持只读和零模型调用。字符按Unicode码点计数，包含换行与空白。
- 新任务冻结清理版本、实际发送正文、系统提示词、输出schema及请求指纹。凭证在发送前脱敏，重试复用冻结输入。原始位置和内容指纹继续作为覆盖与幂等身份，预处理升级保留成功记录。旧待调用任务先核验原冻结指纹，再迁移基础载荷清理并持久化新请求，沿用旧提示词、schema与其余文字，后续重试复用该材料。已有模型结果零调用恢复，输出端同样剥离载荷。
- 预算按准备后的输入计算，包含上下文、提示词和结构指令。正式记录保存清理身份、正文规模、实际请求规模及供应商usage。session正文统计按唯一原消息位置汇总，上下文与多次尝试计入实际调用统计。
- 所有模式先剥离已识别二进制和编码载荷，覆盖媒体data URL、长Base64/十六进制、转义字节、hex dump、Buffer、明确encoding与字节字段。用来源中实际出现的原路径替换。缺失或歧义使用“文件路径未知”。不生成载荷大小、哈希或媒体描述。原始session继续支持回查。短哈希、错误码和位掩码保留。无字段说明的连续编码串识别阈值为512字符，避免误删短业务值。
- off仅关闭额外文字精简，基础载荷清理始终执行。conservative保留用户、助手文字及调用参数（载荷除外），提取已识别包装并折叠可靠成功日志和同段完全重复结果。截断或未知包装保留正文。
- aggressive在基础清理后精简工具材料。命令与补丁分别处理，保留执行权限、执行原因和工作目录。补丁按关键条件优先节选。工具输出按状态、诊断、约束和首尾节选，完整失败诊断保留。普通工具结果预算1800字符、补丁/单条命令3000字符、长行320字符，定位标记和路径另计。节选写明原消息位置。用户与助手文字保留。模型请求省略逐消息时间和指纹冗余，保留position/role/content与整体源时间，原审计元数据保留完整来源身份。
- 工具调用关联使用适配器可选call_id元数据，指纹算法保持原样。只有来源明文路径参与替换。路径无法从编码反推。保留路径不意味着DeepSeek会读取本机文件或理解媒体内容。
- 沿用JSON、退出码、原子落库、租约及凭证边界。真实session、任务原文、模型正文、运行数据库与密钥保留在忽略目录。
