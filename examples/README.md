# 可保留的演示库

先构建项目，再运行：

```powershell
node examples/create-demo.mjs
```

脚本通过真实 `dist/cli/main.js` 在独立的 `os.tmpdir()` 子目录生成演示库，不接收现有库路径。生成期间启动本地服务，结束时停止该服务。演示库与示例原件会保留，脚本打印其位置和预览启动、停止命令。演示任务的模型预算为零。

演示包括 Markdown、TXT、JSON 和未知扩展名原件，两个标签、人工接受与拒绝各一条、若干待判断候选，以及带阅读顺序的体系节点。Markdown 模板中的占位符在导入前替换为本次真实 UUID。查询、解析状态、引用完整性和核心 `check` 在生成时直接验证。

按输出的命令启动预览后，可用 `demo-manifest.json` 查找指南 UUID、标签、体系和其它命令。预览后执行对应停止命令。演示库在系统临时目录中，后续系统清理临时文件可能将其移除；需要长期保存时请使用正式备份命令另存。
